# Contributing Solutions

Thanks for helping improve this problem-solving repository.

## Directory naming

Use the problem number and a short, lowercase slug:

```text
0001-two-sum/
0268-missing-number/
```

Keep the original problem number (including leading zeros) so directories sort consistently.

## What to include

For each solution, include the source file in the language used. When useful, add a short README containing:

- Problem link and a one-sentence summary.
- Approach and why it works.
- Time and space complexity.
- A few representative examples or edge cases.

Do not copy the full problem statement when a link is sufficient.

## Correctness checklist

Before submitting a solution:

1. Check the smallest valid input and boundary values.
2. Consider duplicates, negative values, empty collections, and overflow where relevant to the problem.
3. Compile or run the solution using the language's expected version.
4. Keep unrelated formatting or generated LeetHub files unchanged.

## Pull requests

- Use a focused title such as `Add Java solution for 0001 Two Sum`.
- Explain the algorithm and complexity in the description.
- Mention the command used to test the solution and its result.
- Keep one logical contribution per pull request.

The root README is synchronized with LeetHub topic metadata; avoid manually editing generated sections unless updating the source of that metadata.
